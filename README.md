# -Pixel-GP-2D-Top-Down-Retro-Pixel-Racing-
🏎️ Pixel GP — 2D Top-Down Retro Pixel Racing (v0.5.1)  Pixel GP 是一款基於 HTML5 Canvas 與 Web Audio API 打造的俯視角（Sky-View Top-Down）2D 復古像素賽車遊戲，支援 PC 瀏覽器鍵盤操作與手機觸控直覺遊玩。遊戲採用單一 HTML 檔案、零外部素材依賴架構（所有像素賽車、賽道材質、路緣石、粒子特效與引擎音效皆由程式碼即時程序化生成），完美還原 Imola（伊莫拉）、Suzuka（鈴鹿） 與 Monaco（蒙地卡羅） 三大經典 F1 級賽道的真實彎道幾何與駕駛樂趣。
