- # 🏎️ Pixel GP — 2D Top-Down Retro Pixel Racing (v1.3.0)

**Pixel GP** 是一款基於 HTML5 Canvas 與 Web Audio API 打造的**俯視角（Sky-View Top-Down）2D 復古像素賽車遊戲**，支援 PC 瀏覽器鍵盤操作與手機觸控直覺遊玩。遊戲採用單一 HTML 檔案、零外部素材依賴架構（所有像素賽車、賽道材質、路緣石、粒子特效與引擎音效皆由程式碼即時程序化生成），完整收錄 **7 大傳奇 F1 經典大獎賽賽道（含新加坡濱海灣夜間街道賽）**，並全面支援**繁體中文／日本語／English 三語系切換**與**職業生涯模式（Career Mode）**。

🎮 立即線上遊玩（Play Online — 支援電腦瀏覽器與手機全螢幕觸控）：
👉 https://pennypixellab.github.io/-Pixel-GP-2D-Top-Down-Retro-Pixel-Racing-/

### 3. 動態天氣、5 配方輪胎庫存、自動進站選胎與 VSC 虛擬安全車

* **真實賽道降雨機率與動態天氣（`0% ~ 100%` 路面濕度）**：支援 **☀️ 晴朗乾地 (Dry)**、**🌦️ 動態天氣 (Dynamic)** 與 **🌧️ 傾盆大雨 (Wet)**（生涯模式強制採用各賽道真實氣候動態天氣）。
* **5 大乾濕輪胎配方與週末套數配額（`🔴 Soft ×3` / `🟡 Medium ×2` / `⚪ Hard ×2` / `🟢 Inter ×3` / `🔵 Wet ×2`）**：
  * **乾胎三配方**：**🔴 軟胎 Soft**（抓地力 `+8%`、加速 `+4%`）、**🟡 中性胎 Medium**（均衡耐磨）、**⚪ 硬胎 Hard**（磨損速率僅 `0.58x`，適合長距離免進站）。
  * **雨胎雙配方**：路面濕度 `20%~65%` 適用 **🟢 半雨胎 Inter**；暴雨濕度 `>55%` 適用 **🔵 全雨胎 Wet** 防止水漂打滑。
* **外移獨立分支 Pit Lane 與全自動進站選胎（`🤖 AUTO PIT`）**：
  * `🔧 PIT IN` 進站引道設於主賽道右側紅白路緣石外側（`edgeOffset = 0.58x`），正常靠右超車絕不誤入 Pit。
  * 點擊 **「🔧 預約進站」** 或主動駛入引道後，由 `🤖 AUTO PIT` 自動駕駛進站並彈出 **5 配方大面板（即時顯示各胎剩餘套數與技師推薦）**，6 名像素技師圍車換胎後自動恢復 `100%` 全新耐久度並駛出匯入主賽道。
* **⚡ 1 圈排位賽衝刺模式（固定晴朗乾地 + 🔴 紅胎 Soft）**：正賽前可進行 1 圈無車阻擋的單圈排位衝刺（不扣正賽輪胎配額），決定正賽 P1～P8 起跑格位，奪得 P1 桿位立領 **`+$10,000`** 獎金。
* **⚠️ VSC 虛擬安全車黃旗策略窗口**：正賽突發事故觸發 `7.5 秒` VSC 全場限速 `72%` 並禁用 DRS，此時進站換胎損失時間比平時大幅減少 **40%**。

### 4. 🔋 ERS 電能回充、1.0s 追擊 DRS、真空尾流與 S1/S2/S3 紫綠黃賽段遙測

* **🔋 ERS 電能回充與 160kW 超車推進系統**：
  * 支援 **⚖️ 均衡自動 (`BALANCED`)**、**⚡ 超車推進 (`OVERTAKE`，出彎加速 `+9%`、極速 `+5.5%`)** 與 **♻️ 優先回充 (`HARVEST`)** 三種模式，過彎減速、甩尾或 VSC 期間自動透過 MGU-K 回收動能充電。
* **真實 F1 1.0 秒追擊 DRS 規則與 0.85 秒真空尾流（Slipstream）**：僅限位於 DRS 區、路面濕度 `<45%` 且距離前車 **`<= 1.0 秒`** 的追擊後車才可開啟 DRS；距離前車 `<= 0.85 秒` 自動獲得真空尾流直線牽引加速。
* **📊 F1 三賽段紫/綠/黃刷圈速差遙測（`S1` / `S2` / `S3`）**：右上角即時顯示三賽段獨立秒數與顏色燈號（**🟣 紫段：全場最快**、**🟢 綠段：個人進步**、**🟡 黃段：區間較慢**）。

## 🚀 快速部署與遊玩指南 (Quick Start & GitHub Pages)

本專案為 **100% 純前端單一檔案架構（Zero-Build Single HTML File）**：

1. 下載專案中的 `imola_pixel_racer.html`（或重新命名為 `index.html`）。
2. 直接雙擊在任何現代瀏覽器（Chrome / Safari / Edge / Firefox）中開啟即可遊玩。
3. 若部署至 GitHub Pages：上傳為 `index.html` 後於 Repository Settings 啟用 GitHub Pages，即可透過公開網址在電腦與手機瀏覽器全螢幕暢玩！
