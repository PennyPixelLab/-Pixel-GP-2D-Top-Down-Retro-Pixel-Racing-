# 🏎️ Pixel GP — 2D Top-Down Retro Pixel Racing (v0.5.1)

**Pixel GP** 是一款基於 HTML5 Canvas 與 Web Audio API 打造的**俯視角（Sky-View Top-Down）2D 復古像素賽車遊戲**，支援 PC 瀏覽器鍵盤操作與手機觸控直覺遊玩。遊戲採用單一 HTML 檔案、零外部素材依賴架構（所有像素賽車、賽道材質、路緣石、粒子特效與引擎音效皆由程式碼即時程序化生成），完美還原 **Imola（伊莫拉）**、**Suzuka（鈴鹿）** 與 **Monaco（蒙地卡羅）** 三大經典 F1 級賽道的真實彎道幾何與駕駛樂趣。

## ✨ 遊戲核心特色 (Core Features · v0.5.1)

### 1. 雙模式正交向量物理引擎（貼地轉彎 × 高速自動飄移）

遊戲將車體速度即時分解為**車頭前向分量（Forward Velocity）**與**側向滑移分量（Lateral Slip Velocity）**，創造兼具真實走線與爽快甩尾的手感：

* **貼地抓地走線（Grip Cornering）**：在一般車速或微幅修正方向時，輪胎提供極高側向抓地力（`lateralGrip: 8.5 ~ 11.8`），讓玩家精準貼近彎心（Apex）並享受順暢的出彎加速。

* **高速自動飄移（High-Speed Auto-Drift）**：當入彎車速超過臨界點（`driftThreshold`）並大幅轉向，或在轉向時點按煞車／手煞車，車輛會自動切入**高速飄移模式（DRIFT MODE）**，側向抓地係數動態降至 `1.85 ~ 2.95`，同時維持高達 `99.4% ~ 99.7%` 的前向動量守恆，伴隨雙輪黑膠胎痕、白煙粒子與車尾排氣火花。

### 3. 高辨識度賽道視覺導引系統

* **路面彎道編號與黑黃急彎方向牌**：每個彎心內側印有醒目 `T1` ～ `T19` 編號牌，外側緩衝區配置高對比黑黃相間方向指示牌（`◀ LEFT` ／ `RIGHT ▶`）與路面指向箭頭，高速衝刺時依然清晰預判入彎方向。

* **F1 紅白／藍白路緣石（Curbs）物理回饋**：壓上彎心路緣石可獲得 **+14% 入彎轉向加成**，並觸發 88Hz 壓石音效與手機微震動回饋（`navigator.vibrate`）；衝出草地則會受到 **52% 極速限制與 3.2 倍泥地阻力**。

* **DRS 可變尾翼加速區與五燈龍門架**：於指定大直線全油門行駛時自動開啟 DRS（極速與加速提升 **+7%**）；起終點線設有 8 車位交錯起跑格（Staggered Starting Grid）與 F1 五燈號誌龍門架。

### 5. Ghost Car 最佳單圈殘影與實時遙測 HUD

* **20Hz 軌跡取樣與內插重播**：自動記錄每條賽道的個人最佳單圈（Personal Best），下一圈起以半透明青色殘影車（Ghost Car）同場重播，並於頂部顯示實時秒差（`Δ GHOST +/-0.00s`）。

* **雙排固定不跳動頂部遙測列**：第一排顯示單圈計時、最佳紀錄與快捷鍵；第二排完整顯示**賽道全名、難度標籤與當前彎道全名（含單圈進度百分比）**，絕不因長彎名而跳動換行。

* **右上角透明 F1 三區段小地圖**：以紅（Sector 1）、青（Sector 2）、黃（Sector 3）三色標示賽道區段，同步顯示玩家、Ghost 殘影與彎道編號點位。

* **自由圈數選擇與完賽結算面板**：計時模式支援選擇 **1 圈 / 3 圈 / 5 圈 / 10 圈**，跑完自動彈出完賽成績單（總用時、最佳單圈、分圈明細、新紀錄標章）。

## 🚀 快速部署與遊玩指南 (Quick Start & GitHub Pages)

本專案為 **100% 純前端單一檔案架構（Zero-Build Single HTML File）**，無需安裝任何 Node.js 套件或編譯工具：

### 方式一：本地直接遊玩

1. 下載專案中的 `imola_pixel_racer.html`（或重新命名為 `index.html`）。

2. 直接使用任何現代瀏覽器（Chrome / Safari / Edge / Firefox）雙擊打開即可遊玩。

### 方式二：一鍵部署至 GitHub Pages（支援手機掃碼即玩）

1. 在 GitHub 建立一個新的公開儲存庫（Repository），例如 `pixel-gp-racer`。

2. 將遊戲檔案重新命名為 **`index.html`**，連同本 **`README.md`** 一起上傳至儲存庫根目錄（`main` 分支）。

3. 進入 GitHub 儲存庫的 **Settings** ➔ 左側選單點擊 **Pages**。

4. 在 **Build and deployment** 下方：

   * **Source** 選擇 `Deploy from a branch`。

   * **Branch** 選擇 `main` 並將資料夾設為 `/ (root)`，點擊 **Save**。

5. 等待約 1 分鐘後，即可透過 `https://<你的GitHub帳號>.github.io/pixel-gp-racer/` 在電腦與手機瀏覽器直接全螢幕遊玩！
