# 🏎️ Pixel GP — 2D Top-Down Retro Pixel Racing (v1.0.3)

**Pixel GP** 是一款基於 HTML5 Canvas 與 Web Audio API 打造的**俯視角（Sky-View Top-Down）2D 復古像素賽車遊戲**，支援 PC 瀏覽器鍵盤操作與手機觸控直覺遊玩。遊戲採用單一 HTML 檔案、零外部素材依賴架構（所有像素賽車、賽道材質、路緣石、粒子特效與引擎音效皆由程式碼即時程序化生成），完整收錄 **7 大傳奇 F1 經典大獎賽賽道（含新加坡濱海灣夜間街道賽）**，並全面支援**繁體中文／日本語／English 三語系切換**與全新**職業生涯模式（Career Mode）**。

### 2.5. 動態天氣、5 配方乾濕輪胎與 Pit Stop 進站策略系統（Tire Wear, Pit Lane & Dynamic Weather · v0.9.0 ~ v1.0.3）

* **三種天氣模式與實時路面含水量（`0% ~ 100%`）**：支援 **☀️ 晴朗乾地 (Dry)**、**🌦️ 動態天氣 (Dynamic)** 與 **🌧️ 傾盆大雨 (Wet)**，具備像素降雨視覺、車尾水花噴霧粒子與左上角即時濕度計（`#hudWeatherBadge`）。
* **濕地雨胎擴充（🟢 半雨胎 Inter / 🔵 全雨胎 Wet）**：當路面濕度達 `20%~65%` 時 **🟢 半雨胎 Inter (I)** 發揮最佳破水抓地力；當暴雨濕度 `>55%` 時 **🔵 全雨胎 Wet (W)** 完全防止水漂打滑（Aquaplaning）。

* **三大乾胎配方自由選擇（Soft 🔴 / Medium 🟡 / Hard ⚪）**：
  * **🔴 軟胎 Soft (S)**：抓地力 `+8%`、出彎加速 `+4%`，磨損速率 `1.52x`，適合短途衝刺與 Undercut 強攻。
  * **🟡 中性胎 Medium (M)**：抓地力與耐磨度完美均衡（`1.00x`），適合 3～5 圈標準大獎賽。
  * **⚪ 硬胎 Hard (H)**：超高耐久度（磨損速率僅 `0.58x`），抓地力 `0.94x`，適合長距離免進站策略。
* **實時輪胎耐久度與「抓地力懸崖（The Cliff）」**：左上角 HUD 即時顯示輪胎耐久度百分比（`100% -> 0%`），低於 `40%` 進入顆粒化衰退，低於 `20%` 觸發抓地力懸崖與 `⚠️ BOX BOX!` 進站警報。
* **真實 F1 1.0 秒追擊 DRS 規則**：在 8 車競速中，僅限位於 DRS 區、路面濕度 `<45%` 且**距離前車 1.0 秒內 (`<=1.0s`) 的追擊後車**才可開啟 DRS（領跑者 P1 不可開啟）。
* **真正的獨立分支 Pit Lane 維修通道與 6 名像素技師換胎**：全 7 條賽道於主直線右側均設有實體分離的 **進站引道 (`🔧 PIT IN ▶`) → 水泥護牆 (`PIT WALL`) → 4 座車隊維修車庫 → 6 名像素技師圍車換胎停靠格 (`[🔧 PIT BOX]`) → 出站匯入引道 (`◀ PIT OUT`)**。
* **按賽道長度比例規定圈數（`3圈` / `短程 Short` / `中程 Medium` / `長程 Long`）**：根據每條賽道實際長度自動換算對應圈數（短程 4~6 圈、中程 6~10 圈、長程 10~15 圈）。
* **第 4 款高辨識度新賽車「混動型 · Apex Hybrid V6」**：青色電光塗裝搭配霓虹黃拉花，兼具 ERS 出彎電能高加速與 **`-18%` 省胎特性**。

### 3. 雙模式正交向量物理引擎（貼地走線 × 高速甩尾飄移）

* **貼地抓地走線（Grip Cornering）**：輪胎提供強大側向抓地力，精準貼近彎心（Apex）並享受順暢的出彎加速。
* **高速自動飄移（Drift Mode）**：入彎大腳轉向或搭配煞車時自動觸發甩尾，維持高達 **99% 前向動量守恆**，伴隨雙輪輪胎胎痕、白煙粒子與車尾排氣火焰。
* **8 車 AI 避障與實時名次計算（POS P1~P8）**：基於 Spline 弧長與正交切線投影，毫秒級更新超車名次，且 AI 難度維持攻守兼備的平衡值。

### 4. 三語系即時切換（繁中 / 日本語 / English）

頂部導覽列與主選單支援一鍵即時切換語言，手機端採用寬版人體工學按鈕排版，確保任何語言下文字皆清晰完整、不超出格子、不跳動換行。

## 🚀 快速部署與遊玩指南 (Quick Start & GitHub Pages)

本專案為 **100% 純前端單一檔案架構（Zero-Build Single HTML File）**：

1. 下載專案中的 `imola_pixel_racer.html`（或重新命名為 `index.html`）。
2. 直接雙擊在任何現代瀏覽器（Chrome / Safari / Edge / Firefox）中開啟即可遊玩。
3. 若部署至 GitHub Pages：上傳為 `index.html` 後於 Repository Settings 啟用 GitHub Pages，即可透過公開網址在電腦與手機瀏覽器全螢幕暢玩！
